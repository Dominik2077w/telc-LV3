## 界面中的新增标记

- 题组列表显示绿色 `2026.9 新增 N`，N 为该组新增练习记录数。
- 正在练习的新题在标题下显示 `2026.9 新增`，翻面后仍保留；原有题目不会被批量标成新增。
- 勾选 `只练 2026.9 新增` 后，列表及练习队列都只包含新增题。原题组中补入的个别新题也能单独练习。
- `addedIn: "2026.9"` 是持久标记，不依赖首次打开日期。Baustein 21 的替换语料也作为本版新内容标记。

## 复现与检查

导入脚本只接受已经复核的 PDF 指纹，先完成解析和校验再写入；重复运行不会重复添加题目。Python 需要 `pypdf`，日常运行静态网页不需要该依赖。

```bash
python -m pip install pypdf
python scripts/update-corpus-2026-09.py "/path/to/2026实时更新2026.9(腾讯文档实时更新）.pdf" --dry-run
python scripts/update-corpus-2026-09.py "/path/to/2026实时更新2026.9(腾讯文档实时更新）.pdf"
node scripts/check-corpus.js
python -m unittest discover -s tests -p test_corpus_import.py
npm run check
npm run build
```

源文件指纹与各模块总量见 `data/corpus-2026-09.json`，LV3 逐组答案清单见 `docs/lv3_analysis.md`。以后若收到另一版 PDF，应先复核差异并更新解析规则与预期数据，不能仅修改指纹。
