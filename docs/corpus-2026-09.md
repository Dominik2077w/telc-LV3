## 重建与检查

```bash
python -m pip install pypdf
python scripts/update-corpus-2026-09.py "/path/to/2026实时更新2026.9(腾讯文档实时更新）.pdf" --dry-run
python scripts/update-corpus-2026-09.py "/path/to/2026实时更新2026.9(腾讯文档实时更新）.pdf"

npm run check:hv1
npm run check
npm run build
```

导入先核对 PDF 指纹、页数、模块页码和完整数量，失败时不覆盖题库。JS 与 LV3/HV1 的 JSON 副本同步生成，重复导入不增加记录。未来更换 PDF 版本时须一起复核页码、标记规则、图片和数量，不能只修改指纹。

HV1 听音功能的界面与本地音频工具保留。长稿同样直接从本 PDF 提取；重建只会保留朗读文本完全相同且文件存在的合成音频引用，不从旧库继承任何题干、答案或翻译。HV2 的练习干扰项为独立编写的无关主题陈述，不写回题库。原 PDF 与绝对路径不进入发布包。
