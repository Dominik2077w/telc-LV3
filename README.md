# telc C1 Hochschule Trainer

本地静态练习应用，包含 LV1、LV2、LV3、HV1、HV2、Baustein、口语及写作八个模块。

全部语料以用户提供的 329 页《2026实时更新2026.9(腾讯文档实时更新）.pdf》为唯一来源重新提取覆盖，共 **1800 条练习记录**。每条题目记录来源页码。旧 Excel 精选、额外语法卡和 PDF 未收录的历史题组已移除。PDF 未提供 HV2 的错误选项；练习中的两个干扰项是独立编写的无关主题片段，不通过否定或改写正确答案生成，也不借用其他题目的正确答案。

Baustein 的正确填法同样取自 PDF，另行编写的干扰项见 `baustein-quiz.js`，不写回原始语料。

详细范围、数量、照片转录、存疑项及重建方法见 [语料说明](docs/corpus-2026-09.md)。HV1 说明见 [来源核对](docs/hv1-source-2026-09.md)。PDF 本身不提交到仓库。

## 使用

```bash
npm run serve
```

打开 [本地应用](http://localhost:4173/index.html)。按题组、顺序或随机顺序练习，可启用错题轮回和只练 2026.9 新增。

- LV1：每篇先预览正确填入句的顺序，可在“完整列表”和“点序号看答案”间切换；按钮模式下点下方 1–6，在上方查看对应正确句，也可按数字键切换。再将句子打乱逐条选择第几空；选择后立即判分并显示正确位置。按原文数量生成按钮，另有“没有（不填入本文）”，数字键 `1–6` 作答，`0` 选没有，`Enter` 继续。21 篇完整文章各 6 空，共 126 句；Teil 17 待定无题。此 PDF 未列出多余选项，不自行编造；引擎支持原文明确标出的未使用项。错题轮回先重新预习整篇，再重练其全部句子。
- LV2：A–E 段落卡片、原文题项配对和全局排序；存疑映射不评分。
- LV3：Richtig / Falsch / Nicht im Text 及标题题；来源未标答案的题不判错。
- HV1：先预习 Sprecher 1–8 的正确顺序，再将左侧一列八句话连到右侧第 1–8 位。点一句、点一个空格即生成连线；点已连空格可取消，重新连接会释放旧位置和被占用位置的旧句，句子列表保持固定。每卡保留德语短句与录音按钮，顶部统一控制音频进度，不显示听力原文。八条全部连接后统一提交，逐项显示正误和正确位置，右侧错位空格提示应接的句子，并可展开完整正确顺序。错题轮回重新连接整组八项。左下角“HV1 模式”还可切换到“先记顺序 → 随机逐题选位置”：每篇八句话打乱后逐题出现，选择原来的第 1–8 句，选后立即核对并显示正确位置，数字键 `1–8` 作答，`Enter` 继续；篇末汇总并支持按同一模式错题轮回。也可逐句复习；Mode 无顺序答案，使用陈述复习卡。
- HV2：预习时展示完整句与中文；三选一练习的三个选项均为省略句子开头的补全片段，并统一省略末尾句号。正确选项取自 PDF；两个干扰片段独立编写，不复用其他题目的正确答案，答题后查看 PDF 中文和来源说明。
- Baustein：每轮每篇先按空格编号预习全部答案句与完整中文，再逐空四选一。题面仅挖空当前词语，其他空填好；选项按介词搭配、形容词词尾或近义辨析、动词形式和固定搭配、名词词形等编写，每次重新打乱选项，同一题再次出现时正确项必定换位置；数字小键盘 `4` 左上、`5` 右上、`1` 左下、`2` 右下（或 `A–D`）选择，手机也保留两列排版。选择后立即判分，显示正确填法、完整句与中文，另附逐空中文解析、相关规则与可展开表格。动词覆盖六个人称的六时态、两类虚拟式、命令式和分词；被动题补同一动词的被动表，形容词配强/弱/混合词尾表，名词配单复数四格表。433 空均有专门解析，涉及 128 个动词；原文疑似错误单独标注，不当作标准语法。语法补充存于 `baustein-explanations.js` 与 `baustein-grammar.js`，不改 PDF 答案，按 `Enter` / `→` 继续，错题自动进入下一轮；中德对应高亮在预习、题面和反馈中保留。433 个可核对的空进入选择练习；Teil 18 的 22 个答案字母以及缺文的 Teil 21/38 仅预览。干扰项是练习编写内容，原文列出的其他正确写法保留在反馈中，不会被当成错误选项。
- 口语、写作：完整原文任务及观点；原文没有中文时明确标注。

HV1 合成音频与对应长稿均取自这份 PDF。音频工具在 `scripts/local/qwen3-tts/`，可用的压缩音频随构建复制；没有音频的题仍可阅读原文练习。

## 重建与检查

```bash
python -m pip install pypdf "PyMuPDF<1.27"
npm run extract -- "/path/to/2026实时更新2026.9(腾讯文档实时更新）.pdf" --dry-run
npm run extract -- "/path/to/2026实时更新2026.9(腾讯文档实时更新）.pdf"
npm run check:corpus
npm run check:hv1
npm run check:hv2
npm run check:baustein
npm run check
npm run build
```

导入校验指纹、页数和完整题量后覆盖题库。`npm run build` 输出 `dist/`。PDF、来源绝对路径和本地模型不进入发布包。

## 发布与手机使用

项目站点：[telc Trainer](https://dominik2077w.github.io/telc-LV3/)。推送到 main 会由 GitHub Actions 校验、构建并发布，此次本地修改不会自动上线。

手机在 Safari 或其他浏览器打开站点，使用“题组 / 设置”选择范围并开始练习。HV2 三个选项纵向排列并支持触屏选择；屏幕较窄时 LV2 配对使用原生选择控件，卡片内容可换行滚动。资源版本号会在更新时递增，以便加载最新练习。
